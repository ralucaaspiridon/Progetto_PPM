# Progetto_PPM
Questo progetto è un'esercitazione scolastica focalizzata sullo sviluppo Front-End, con l'obiettivo di replicare il layout, la tipografia e la responsività del sito di informazione https://www.inquirer.com/. 
## 🎯 Obiettivi del Progetto
L'obiettivo principale di questo lavoro è stato quello di analizzare e riprodurre la struttura di un sito d'informazione moderno, focalizzandosi su:
- **Gerarchia Visiva:** Gestione di titoli, sottotitoli e sommari.
- **Responsività:** Adattamento del layout da desktop a mobile.

## 🛠️ Tecnologie Utilizzate
- **HTML5:** Strutturazione semantica (header, section, article, footer).
- **CSS3 Avanzato:** - Flexbox per l'allineamento dei contenuti.
  - Media Queries per il design responsivo.
  - Funzione `clamp()` per la gestione fluida dei font.
- **Bootstrap 5:** Per il sistema a griglia (Grid System) e le utilità di spaziatura.

## 📁 Struttura dei File
Il progetto è organizzato in modo modulare per facilitare la manutenzione:
- `index.html`: La struttura portante della home page.
- `style.css`: Stile generale per gli articoli e le sezioni principali.
- `header-style.css`: CSS dedicato esclusivamente alla testata e alla navigazione.
- `footer-style.css`: CSS dedicato al pié di pagina e alle sezioni informative finali.
